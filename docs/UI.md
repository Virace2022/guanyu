# UI 规范

观鱼采用可选主题色、单色小鱼和逐队编辑结构。设置、团播名单与即时操作使用统一控件语言；原生页面增强沿用斗鱼自己的资源和视觉。

功能行为见 [FEATURES](FEATURES.md)，模块和数据职责见 [ARCHITECTURE](ARCHITECTURE.md)。

## 视觉与基础控件

- 自有窗口提供跟随页面、浅色、深色；主题色只提供斗鱼橙（默认 `#ff5d23`）、青绿、湖蓝、藤紫、玫红五个预设。点击色块立即预览，保存后保留。主按钮统一白字，操作背景从主题色按需压暗，普通文字对比度至少 4.5:1；悬停继续略微压暗。品牌小鱼和色块保留原主题色。跟随模式读取斗鱼官方主题状态，切换官方右下角按钮时同步。字体使用系统中文字体，不加载在线字体。
- 通用外观中的主题与主题色均采用标题在上、选项在下的分组布局，左右边缘对齐。三种主题直接展开为等宽单选项，五个主题色等宽排列；窄窗口下色点与名称上下排列，两组之间保留统一间距。
- 所有自有小鱼以 `assets/brand/guanyu.svg` 为唯一运行来源，经 `FishIcon.svelte` 复用。历史设计图仅作参考，不作为必须实现的界面或人数约束。
- 使用 Svelte 5、原生表单控件和自有薄组件。Bits UI 在复杂交互需要时接入，当前尚未安装。
- 设置内容区使用 `--field-gap: 10px` 和 `--section-gap: 18px`。连续开关位于 `.option-list`，只在相邻行间画线，分区自身提供一条分割线。
- 下拉和直接输入框常规约 40px、紧凑布局约 36px 高，选择框随内容区伸展；宽度低于 480px 才将标签移到控件上方。原生下拉保留选项和键盘行为，使用统一 SVG 箭头与右侧留白。
- 主题细滚动条限定在自有 Shadow DOM。窗口、菜单和内容切换使用短动效，遵循系统“减少动态效果”。
- 设置说明聚焦功能范围和必要操作，不重复提示立即预览、保存生效、放弃恢复或静态默认状态；保存与未保存反馈由统一底栏和关闭确认承载。独立保存范围、数量含义等影响操作判断的信息保留。

## 设置与草稿

设置使用分类导航和独立内容区，十一类内容不拼成整页长表单。窄窗口采用完整分类下拉框，保存栏保持可达。

设置固定为 760×600px，视口不足时缩小至可用区域，切换分类不改变窗口尺寸。页头 52px、分类行 34px、主标题 20px、分区标题 15px；导航与正文分别填满剩余高度，仅在各自内容溢出时滚动，滚动条留在所属区域内。宽度不超过 680px 时改用显示当前分类的完整下拉框。保存栏固定在窗口底部；按实际浏览器可用区域验收，不按屏幕物理分辨率推断。导航使用“背包”“签到”短名称，多屏图标为四格。

| 内容 | 交互与生效 |
| --- | --- |
| 外观、页面整理、原生屏蔽、弹幕标记与进场提示、团播布局与入口显示 | 跨分类保留草稿，立即预览，保存保留、放弃恢复 |
| 其他普通偏好 | 修改草稿，跨分类保留，点击“保存全部”统一应用 |
| 需重新初始化的项 | 仍进入统一草稿，明确标注刷新要求 |
| 预览、队员展开、音量与镜像等即时状态 | 本页立即操作，按功能自身范围保留 |
| 团播名单 | 独立编辑器草稿，点击“保存并应用”后生效 |
| 导入/导出 | 导入修改草稿，导出当前草稿，不伪装成持久开关 |

分类显示未保存标记，底栏提供“放弃更改 / 保存全部”，点击任一按钮完成操作后关闭窗口；未修改时也可点击关闭。改回已保存值后清除标记；保存失败保留窗口、草稿和错误状态。设置保存不合并另一个名单编辑器的草稿。

未保存数量按分类计数。从设置打开多屏或续牌，先处理统一草稿；保存后使用新值，放弃后使用原值，继续编辑、Escape 和保存失败不提前打开。跨分类校验失败时回到对应分类，滚动并聚焦字段，保留其他草稿。多屏当前状态和开启入口放在设置内容顶部；签到检查仅作用于已保存开启的任务，草稿待保存时解释原因。

点击设置窗口外的遮罩、关闭按钮或按 Escape 共用关闭逻辑；有未保存修改时，提供“保存并关闭 / 放弃更改 / 继续编辑”。从窗口内部拖到外部不触发关闭。标签页关闭沿用浏览器离开确认。名单编辑器遇到活动变化或退出时同样处理未保存草稿。

所有自有窗口阻止键盘事件继续传播至播放器，文本可输入空格和官方快捷键字母，方向键保留控件行为，Escape 先关闭当前窗口或弹层。官方快捷键的开启状态和自定义按键始终由官方设置维护。导航统一使用线形 SVG 图标；主题文字采用随浅深主题混合的文字色，与选中底色的对比度至少 4.5:1。

## 入口与原生菜单

小鱼仅在具有 `#js-player-main` 宿主的直播间显示，普通模式作为原生右下角工具栏中的独立一项，保留 28px 图标、原工具栏间距和贴边收起行为。没有工具栏时才使用独立入口。网页全屏将同一个入口移到播放器弹幕屏蔽控件左侧，退出还原；直播间宿主消失时撤下入口。首页、分类页和关注页不启动脚本，粉丝牌列表页不显示小鱼。

点击小鱼直接打开设置。普通页面小鱼常态使用主题色，无背景、边框和阴影；网页全屏沿用播放器 32px 点击区，常态白色，悬停和聚焦时使用主题色。团播名单可从设置、团播工具条和脚本管理器菜单进入。

页面操作从可编排的播放器右键菜单调用。编排器左侧显示当前动作，右侧为可添加功能，通过拖入、拖回和排序编辑；保留默认预设，保存前不改变真实菜单。

原生菜单外观通过 `native-menu.css` 和适配层复用，保持文字、字体、配色、分割线和子菜单箭头。主播配置保持预读和悬停展开，移入内容后继续显示，空间不足时向左展开；键盘右方向键/Enter 进入，左方向键返回。

真实开关菜单项保持固定名称，开启时沿用官方“✓ ”前缀，并同步复选菜单角色与选中状态；点击后即时更新，重新打开仍反映真实状态。设置、编辑等动作不显示勾选；多屏入口按实际状态显示“进入多屏 / 退出多屏”，另提供可编排的“编辑多屏”动作。主播配置字段保留旧版 CPU、显卡、设备、系统、场景图标及标题/值两行显示；直播画面使用电视图标，分辨率和帧率紧接名称显示在同一行。未提供的设备字段直接省略。

聊天区收起入口位于常驻榜单标题行，切换榜单仍可用；收起后在贵宾/钻粉人数旁提供恢复按钮。沿用原生 24px 按钮视觉，预留独立空间。

## 团播编辑与页面

名单按可用 CSS 视口动态分配宽度，覆盖 1080p、2K 和 4K 三种 16:9 工作区。进入大桌面布局的最小可用区域为 1440×760 CSS 像素，避免系统或浏览器缩放后约 1589px 宽的实际视口被误归入小窗口。桌面宽度在逻辑 840～1280px 之间连续增长，左栏 156～180px、右栏 232～272px 也连续变化，其余宽度给中间编排区；不能只放大固定窗口或加宽侧栏挤掉成员列数。字号缩放上限 125%，2K 与 4K 保持同一字号档位，4K 通过增加工作区宽度显示更多卡片。高度适度分档，实际宽高均受视口边距约束。

| 验收视口 | 名单实际宽高 | 字号/控件比例 | 中间每行容量 |
| --- | --- | --- | --- |
| 1920×1080 | 1008×720px | 120% | 4 张 |
| 2560×1440 | 1310×820px | 125% | 6 张 |
| 3840×2160 | 1600×900px | 125% | 8 张 |

小桌面保留 760×600px 基准，视口不足时按 32px 总边距收缩，窄屏不铺满剩余高度。当前分区与候选分别滚动，保存栏固定。窄窗口队伍栏改为顶部横排，右侧按窗口的 36% 分配并限制在 180～232px。标题、统计与工具合并在同一条 52px 基准顶栏，底栏 48px；窄窗口将工具换到下一行。中间卡片采用 90px 最小列宽，均匀分配可用宽度，统一 8px 间隔；主区滚动条两侧预留相同空间，整行两侧留白对称。昵称宽度封顶 78px，约六个汉字，单行超出省略。卡片默认只显示头像和居中昵称，整张卡片可拖动；顶部“房间号”开关只控制中间卡片的额外一行，默认关闭，偏好立即保存，不算名单草稿。不显示开播状态和成员手柄。右侧每人使用 36px 基准头像、单行昵称及队伍标记，不显示房间号、开播状态或文字归属。未分配置顶；头像不叠加勾或斜箭头，未分配头像仅在悬停或聚焦时显示添加加号。无队伍时保留人物区和添加入口，保存后重开不会补回队伍。

三栏按内容分配宽度，不以中间能塞下多少卡片为唯一依据。候选列表使用 52px 基准行高、12px 图文间距及 12 / 16px 内边距，昵称和队伍标记之间保留 8px；使用间距及悬停底色区分行，不为每行增加分隔线。排版参考 [Fluent 布局](https://fluent2.microsoft.design/layout)的间距与内容适配原则和 [Fluent 列表](https://fluent2.microsoft.design/components/web/react/core/list/usage)的对齐及扫读原则；具体宽度为本项目结合昵称长度和实际窗口作出的选择。

右侧候选的头像、昵称和行内空白使用同一个按钮，整行点击行为与悬停底色一致；已在当前分区时不重复添加，仍可拖到其他分区。人物资料编辑弹窗跟随当前主题，输入框使用常规字号。

顶部独立人物允许多个，区域名默认“团长”，头像右键菜单可编辑显示名和身份标签，不限定为单一主持人。右侧活动成员标题旁的加号提供“添加自定义直播间”，输入房间号或斗鱼直播间链接，取得资料后加入当前分区。成员跨队出现时仍按真实房间号关联，来源缺失成员保留提示。

队长 / 队员一行右侧保留显示当前色的“队色”入口，点击打开八种常见预设和原生自定义取色器。弹层右端对齐入口并限制在视口内，避免遮住右侧候选；预设色当前选择用 24×24px 正方形外框表示，不增加勾号。选择后收起，Escape 返回入口，点击外部收起。新队优先使用尚未使用的预设色，旧名单补色，保存及分享保留颜色。左侧队名和页面、预览的队伍标题前显示同色小圆点。右侧队员为圆点、队长为五角星，多个归属显示多个标记，完整队名和角色通过悬停与无障碍名称保留；独立人物不加队伍标记。昵称不染色。

卡片的头像、名字和空白处均可发起拖动，人物区、队伍和角色标签互相可达，支持排序和边缘滚动，Escape 撤回拖动。编排卡片拖出会移动该引用；从候选拖入保留其他归属，目标已有时不重复添加。撤出按钮独立位于卡片右上角，与头像不重叠，悬停或聚焦卡片时显示，按钮本身不发起拖动。右键卡片、点击头像、菜单键或 Shift+F10 打开随内容定宽的操作菜单，提供撤出、换队和换角色；方向键选择、Escape 返回头像。队伍保留排序手柄；圆形删除减号绝对定位，平时不占位，悬停或聚焦时队名让位，触屏选中后显示。空队直接删除，非空队确认后只撤回该队分配。

各区域独立滚动，保存和取消入口保持可达；窄窗口通过调整导航和分区排列适配，明暗主题共用布局。

页面分组外壳透明，卡片保留官方背景、边框和圆角，统一高度及文字居中，避免把官方不同宽高比带入同宽格子。隐藏顶图后，普通房间播放器保留导航下 8px，团播首个内容区保留 32px，与名单下方到播放器的留白协调；导航随滚动隐藏时占位不收回，退出网页全屏后恢复原间距。隐藏下方大块内容时增加 24px 底部留白，占位底色读取当前播放器/团播内容实际的不透明背景，未提供时沿用原背景，关闭整理或释放后还原。

优化分类中的“隐藏直播间下方内容”默认开启，统一控制视频精选、鱼吧等大块区域和页脚；与顶图、礼物栏、活动浮窗分别控制，关闭恢复原布局。

团播工具条默认贴右侧收起，露出 36×44px 小鱼手柄，图标居中。小鱼始终位于面板左侧，二者组成一个抽屉，共用同一段 180ms 位移动画；悬停一起向左展开，移入面板保持打开，移出后一起滑回，收回时不提前隐藏内容。点击也可开合，键盘聚焦展开、Escape 收起；收起内容不可聚焦，减少动态效果时直接切换。常态为点击光标，实际拖动时显示抓取光标，网页全屏时隐藏工具条。

团长、队伍与预览分区标题共用同一条样式：10% 不透明度的中性灰背景、6px 圆角、32px 最小高度，文字居中且允许长名称换行，字色沿用活动原生文字颜色。标题与分区内容同宽。队伍列数由自动编排或用户选择确定，不超过非空队伍数，不保留空列。顶部独立人物卡片保留原宽度居中排列。队长与队员使用独立卡片行，队长保留身份标签；卡片外观、开播图片和跳转方式沿用官方。原生成员悬停借用原组件，离开、后台或全屏切换时归还，不用复制的静态 DOM 替代官方交互。

队员卡片布局提供“按人数自动编排”“保留原卡片尺寸”和“固定队员列数”。自动编排同时看队伍数、各队人数与可用宽度：少队五人横排，六人两列、九人三列；多队少人收窄并排，多队多人逐队纵排。卡片不为填满宽容器无限拉长，队伍标题跟随实际内容宽度。原尺寸模式按官方宽高换行；固定列数按用户选择，宽度不足时收缩。旧版未记录选择来源的三列按旧默认转为自动，其余旧固定值保留；新版明确选择固定三列后不再被升级规则改变。

## 房间信息与背包操作

本场已播时长、公会保留图标并紧接原生人气信息。离线播放器中央显示可关闭的上次开播卡片，同时隐藏对应回放推荐；顶部原生上次直播信息保留，观鱼不重复追加。

背包总价值、道具总亲密度留在背包内；“背包”入口沿用原生中性边框和文字，悬停/聚焦跟随主题。月消费直接复用鱼丸、鱼翅的信息项结构与官方 CSS，钱包与显隐眼睛统一为 16px 双色实心图标，钱包扣带、眼白与隐藏斜线使用细节色，配色取自官方鱼丸资源：浅色 `#bbb / #ededed`，深色 `#595a66 / #94959c`，并按字形校正视觉中心；眼睛悬停沿用官方标签的次要字色。标签与金额分开，眼睛按钮默认隐藏金额，显示时悬停查看分类汇总。聊天工具栏只补本房粉丝牌持有时间，文字沿用鱼翅标签的次要字色，保留获得日期提示；个人中心牌表满 300 天强调，不挤占高能、过滤或屏蔽控件。

设置中的粉丝牌房间、常用多屏候选同样复用头像网格。粉丝牌在名字下显示持有天数，悬停保留房间号与获得日期，点击沿用直播间链接；常用候选保留独立移除按钮。团播编辑器沿用已有头像与编排交互。

荧光棒按钮位于充值旁，图标跟随主题色。续牌窗口上限 400px，打开即读取库存、目标与计划；数量变化在本地更新计划，“确认赠送”紧邻输入框。库存、每房、合计三列等宽居中，目标按头像与下方昵称平铺，房间号保留悬停提示；名单独立滚动。确认后逐房赠送，成功在头像上用 260ms 线性描边勾回显，进行中转圈，失败保留提示。昵称下方显示本页累计已送数量，显示设置变化和重新准备计划都保留记录；记录不阻止再次赠送。赠送期间锁定数量和按钮，结束后按钮可再次确认，明确提示会再向全部目标赠送。右上角与 Escape 可关闭，关闭不停止已有赠送；不增加底部关闭栏或第二次确认。专属 CSS 显式挂入 Shadow DOM。

多屏添加与更换小窗同样上限 400px，随内容高度显示；候选按头像和名字网格排列，直播中优先，同状态保留来源顺序。未开播头像置灰且仍可选择，已在多屏或本次已添加的显示勾并禁用；悬停或聚焦未选头像显示加号。候选独立滚动，每次打开回到顶部；更换成功关闭窗口，添加候选后可继续添加。

续牌发送期间就地显示“关闭窗口后仍会继续赠送，可重新打开查看进度”，不让窗口关闭被误解成取消后台执行。

## 预览与提示

预览显示“娱乐功能”，原始布局和分组布局分别说明范围。开启和展开队员时少于 50 个预览槽位直接应用，50 个及以上确认数量并提醒资源占用；0 个槽位说明尚未编排名单或没有其他房间，并提供对应操作。预览主标题和空名单提示使用观鱼主题的文字与不透明底色；分区标题与上方名单共用淡灰圆角样式，保持活动背景上的可读性。

团播工具条用小鱼手柄展开或收起，可沿右侧上下拖动，支持方向键与 Home / End，在本页保留相对位置；窗口尺寸变化时限制在视口内。显示开关位于团播设置，关闭入口不停止业务和预览。

工具条与右键入口共用同一确认逻辑。取消保持原状态，切换布局后重新确认。确认窗口按内容高度布局并限制最大高度，避免继承设置大窗的固定高度。

预览中的本直播间显示占位而不取流。队伍双击放大/还原只影响本队；开启高清原声时提供明确状态，还原立即静音。

## 增益与多屏音量

增益按钮常态白色，悬停和聚焦使用主题色。浮层显示额外百分比、额外倍率和常用档位，统一按加法表示：原声为 0%，+100% 为加 1 倍，设置的 2 倍上限对应 +200%。档位每行四个、最多八个；超出上限的档位禁用，提示包含当前额外百分比上限。没有原声档位时仍提供恢复原声动作，浮层不另加“声音设置”按钮。设置中的倍率输入与“倍”单位紧凑居中，支持 1～5 的小数。

增益图标滚轮每格调整额外 5 个百分点，阻止页面滚动与原生调音量重复触发。浮层或焦点停留时维持控制栏可见，隐藏控件聚焦不滚动页面。

多屏头像和名称复用官方结构、图像与样式，主房间补同款标签，头像右下角显示喇叭角标：

| 设置 | 默认 | 操作 |
| --- | --- | --- |
| 独立控制各直播间音量 | 关闭 | 关闭时点击头像选择唯一发声房间；开启后点击静音/恢复、悬停显示纵向滑条 |
| 标签集中到画面中间 | 开启 | 开启时位于画面内侧角；关闭时各路均在左下角，包含主房间 |
| 主播标签显示方式 | 始终显示 | 多屏设置顶部独立“主播标签”分区，直接展示始终显示、仅显示头像、全部隐藏三个单选项；立即预览，保存保留、放弃恢复 |

集中布局中，头像与音量入口始终贴近中间分隔线，名字向画面外侧排列：左侧画面为名字在左、头像在右，右侧画面为头像在左、名字在右。头像及滑条的位置不受昵称长度影响，拖动后按画面实际位置更新。

滑条显示 0～100% 的房间音量，复用官方轨道与滑块的视觉类和资源（25px 容器、100px 轨道、2px 线条、10px 滑块），填充色跟随观鱼主题。原生 range 保留键盘和拖动操作，总音量独立保留在底部播放器控件。滑条向所属画面内部展开，鼠标移入滑条或键盘聚焦时保持显示；Escape 收起，事件不冒泡到原生音量或拖动处理。

拖动后根据实际位置调整标签，音量随房间走；布局切换不重建播放器。原生左下角位置在控制栏展开时避让其操作区域，收起后恢复原边距。

名字从固定头像旁展开，左侧向左、右侧向右；只展开当前一路。展开约 180ms，离开整个标签及关联控件后等待 600ms，再用约 200ms 收回；拖动音量、键盘焦点停留和菜单打开时保持显示。鼠标点击喇叭不获取持续焦点，滑条在鼠标拖动结束时释放焦点；移出页面或窗口失去焦点时结束悬停。减少动态效果时直接切换。全隐藏在原头像附近保留 44px 小热区，隐藏标签的整个文字容器均不响应鼠标，返回页面需再次移入热区才唤出。

标签右键菜单显示主播名、当前清晰度及副屏的“更换直播间”；主房间标记“当前”并省略换人。画质子菜单使用官方档位和当前生效勾选，切换期间显示状态，失败只反馈目标房间。头像与名字均可右键，菜单键或 Shift+F10 可打开；方向键选择，Escape 先退回子菜单再关闭，焦点返回标签。专用菜单独立于播放器通用菜单编排，空间不足时翻转且限定播放器边界，打开时暂收起音量浮层。

开启多屏时后台自动读取可选画质，菜单不提供会重连画面的“读取清晰度”操作。读取中给出状态，失败重试只取数据；未确认当前实际档位时先展示可选列表，不勾选后台查询请求使用的档位。

首次进入多屏用一次约 4 秒的非阻塞文字说明右键入口；后续隐藏模式进入时仅短暂显露位置。设置保留操作说明，头像提示合并声音和右键操作，不增加常驻更多按钮或画质文字。

## 弹出层与恢复

自有设置、编辑器和独立提示放入 Shadow DOM；设置/名单使用原生 dialog，增益使用原生 popover。原生卡片、菜单、选房面板及标签仍在页面上下文中增强，CSS 限定宿主。

多屏相关绘制顺序为：视频和弹幕 → 音量标签 → 原生控制栏、菜单与选房面板。被面板覆盖的标签不能接收鼠标点击，关闭面板后恢复；保留面板之外的音量入口操作。

窗口宿主被原生页面移除后，重新打开需再次进入模态顶层，不只保留 open 属性。恢复原生页面时只撤回观鱼持有的节点、样式和回调。

后续接入 Bits Portal 时，窗口内弹层留在该 dialog 的 Shadow DOM 子树，禁用默认 body Portal 或指定窗口内 HTMLElement 宿主，`to` 不直接传 ShadowRoot。

## 交互验收

真实页面至少覆盖：入口打开/重开、跨分类草稿、保存与取消、Tab/Shift+Tab、Escape、焦点返回、窄窗口和主题切换。播放器相关交互在网页全屏下核对。

多屏还需核对两种音量模式、集中/左下角布局、拖动与定点换人、控制栏展开、编辑面板覆盖、退出恢复以及媒体节点是否保留。几何尺寸与点击命中分别检查，避免“看得见却点不到”。
