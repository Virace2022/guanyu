# 详细功能列表

安装与配图见 [README](../README.md)。以下按设置中的十一类列出当前功能；默认值和具体行为见[功能说明](FEATURES.md)。

## 播放

| 功能 | 用法 |
| --- | --- |
| 自动网页全屏 | 房间确认开播后进入网页全屏；本页手动退出后保留你的选择 |
| 自动最高画质 | 按官方可用档位和权限选择 |
| 后台保持视频流 | “播放偏好”中的独立开关，默认开启；阻止主屏后台转为纯音频，避免回前台时因此重载 |
| 整改期间继续播放 | 默认开启；临时整改时保留画面与声音，在左上角提示官方原因和扣分，正式封禁与下播保持官方处理 |
| 原生音量滚轮 | 在原生音量入口滚动，每格调整 5% |
| 官方刷新、重连与夜间模式 | 复用官方能力，在原生入口或相应快捷动作中使用 |

## 声音

| 功能 | 用法 |
| --- | --- |
| 额外音量增益 | 播放器增益按钮开启，按主房间记忆；0% 为原声 |
| 增益上限 | 可设额外 +100%～+500%；+200% 表示实际为原声的 3 倍 |
| 常用档位 | 自定义最多八个 0～500% 的整数档位，浮层中一键切换 |
| 增益滚轮 | 在增益图标上滚动，每格调整额外 5 个百分点 |

## 页面整理

| 功能 | 用法 |
| --- | --- |
| 页面整理 | 分别隐藏广告、顶图、播放器下方大块内容、礼物栏、PK 条和活动浮窗 |
| 收起聊天活动区 | 保留贵宾、钻粉人数和恢复按钮，给聊天正文留出空间 |
| 顶栏随滚动显隐 | 在直播间滚动时收起或恢复顶栏 |
| 关播推荐与未读角标 | 分别控制关播推荐关闭和消息未读角标隐藏 |

## 弹幕与特效

| 功能 | 用法 |
| --- | --- |
| 标记整理 | 独立隐藏粉丝牌、钻粉、贵族／至尊、等级及其他前后缀 |
| 隐藏进场提示 | 隐藏聊天底部“谁谁谁来了”的独立提示 |
| 活动及链接消息过滤 | 保存后过滤相应整条消息 |
| 原生特效偏好 | 分别设置全部礼物、消息通知、视频广播、小礼物、进场特效、礼物音效、弹幕皮肤七项屏蔽，进入房间时应用 |

## 团播

| 功能 | 用法 |
| --- | --- |
| 自动识别与手动覆盖 | 识别两种官方活动模板，也可将当前活动设为团播或排除 |
| 自编人物与队伍 | 设置 → 团播 → 名单；编排多个顶部独立人物、队长、队员，修改区域名、显示名和身份标签 |
| 添加自定义嘉宾 | 输入房间号或斗鱼直播间链接，把活动名单外的主播加入编排 |
| 拖放与右键编排 | 拖动整张卡片排序、换队、换角色，右键编辑或撤出；同一成员可在不同队伍中出现 |
| 队色与归属标记 | 八种预设色及自选色；活动成员旁用星形标记队长、圆点标记队员 |
| 保存、分享与导入 | 名单按活动保存；分享码携带人物、分组和队色，导入后保存生效 |
| 分组布局 | 队伍并排或自动排布，队员可按人数、原卡片尺寸或固定列数排列；保留官方卡片及悬停交互 |
| 多人预览 | 工具条 → 开启预览；原始布局预览活动名单，分组布局先看独立人物与队长，再展开队员 |
| 逐队放大与原声 | 双击画面逐队放大；可选放大高清原声，还原后静音 |
| 开播状态与重试 | 自动刷新成员状态；预览失败重试间隔可调 |
| 贴边工具条 | 小鱼展开名单、分组和预览操作，可上下拖动，也可在设置中隐藏 |

团播预览默认静音，是批量查看成员的小画面；下节的多屏用于正式同屏观看，提供逐路声音和画质控制。开启或展开 50 个及以上预览槽位时会先确认数量。

## 多屏

| 功能 | 用法 |
| --- | --- |
| 任意直播间开启 | 设置 → 多屏 → 开启／编辑多屏；选择房间后播放，普通直播间最多四屏，含当前房间 |
| 任意房间加入 | 输入斗鱼房间号或链接；候选合并官方活动成员、团播成员、关注、常用及临时房间 |
| 紧凑选房 | 官方大图列表改成两行 16:9 缩略图，面板内部滚动；顶部显示已选房间，点“×”取消 |
| 头像网格选房 | 添加和定点更换小窗按头像与名字排列，开播优先；已选房间标勾，未开播房间仍可选 |
| 拖动排序 | 拖动画面调整排列，音量与画质选择跟随房间 |
| 副屏声音 | 点标签上的头像喇叭，让副屏也能发声；默认只听一路 |
| 独立音量 | 开启后可多路同时发声；悬停头像拖动本路 0～100% 滑条 |
| 总音量 | 独立模式下，底部音量作为总比例；总音量 50% × 本路 60% = 实际 30% |
| 逐路清晰度 | 右键头像或名字 → 清晰度；按该房间的官方档位切换，选择保留于本次多屏 |
| 定点换房 | 右键副屏标签 → 更换直播间，替换这一格，其余画面继续播放 |
| 标签位置 | 集中到画面交界处，或放回各画面左下角并避让控制栏 |
| 标签显示 | 始终显示、仅显示头像、全部隐藏；后两种可悬停展开，头像位置固定 |
| 候选刷新与退出 | 刷新候选保留在播画面；取消最后一个副屏或选择退出多屏，回到单屏 |

## 房间信息

| 功能 | 用法 |
| --- | --- |
| 本场已播时长 | 原生房间信息行显示时长，悬停查看开播时间 |
| 公会信息 | 在房间信息行补充可取得的公会资料 |
| 上次开播时间 | 未开播时在播放器中央显示上次开播信息，可关闭卡片 |

## 背包与权益

| 功能 | 用法 |
| --- | --- |
| 道具资料 | 背包内查看道具到期、总价值和可提供的总亲密度 |
| 本月消费 | 鱼丸、鱼翅旁显示月消费，默认隐藏金额；点击眼睛切换，悬停查看分类汇总 |
| VIP 到期 | 独立显示可取得的 VIP 到期信息 |
| 粉丝牌持有天数 | 在设置与个人中心牌表查看持有天数，牌表满 300 天突出显示 |
| 聊天区牌龄 | 独立开关，默认开启；聊天工具栏显示本房牌龄，悬停查看获得日期 |
| 主播口袋 | 显示可取得的主播口袋信息 |
| 荧光棒续牌 | 充值旁的荧光棒按钮先展示库存、目标和计划，确认后逐房赠送；每房数量可调，0 表示平均分配 |
| 赠送进度 | 在目标头像上显示进行中、成功或失败，保留本页累计数量；再次确认会再送一轮 |

## 每日任务

| 功能 | 用法 |
| --- | --- |
| 鱼吧签到与补签 | 为全部已关注的鱼吧自动签到，分别记录今日签到与补签结果 |
| 客户端签到 | 先查今日状态，避免重复签到；显示连续与累计签到天数、剩余补签次数及最近日期，关闭自动补签仍可查看次数 |
| 自动补签 | 与客户端签到同组的独立开关，默认开启；首次签到跳过，按官方资格一键补齐最近一周漏签，提交后核对日历 |
| 粉丝家园签到 | 为全部持有粉丝牌的房间逐一完成粉丝家园签到 |
| 粉丝牌弹幕任务 | 默认开启，向未完成每日任务的持牌房间发送一条 `.`；最多两路静默处理，完成后当天不再查询，北京时间零点后重新开始 |
| 官方任务中心积分 | 处理签到及官方已完成观时档位的积分领取 |
| 等级奖励与随机阅读 | 领取已完成等级奖励，阅读后核对官方进度；未确认的进度显示待确认 |
| 临时关注任务 | 只处理原本未关注的房间，任务后恢复；中断后优先处理未完成恢复 |
| 全民星推任务 | 按活动要求为榜单房间签到；开启关注任务时，还会临时关注未关注的房间，随后取关 |
| 提醒、进度与多页协作 | 设置中调整任务和鱼吧提醒、查看进度；关闭设置窗口后继续运行，同账号多页共享调度 |
| 星推荐红包自动领取 | 默认开启，每分钟检查当前房间，预计开抢前 2 秒开始连续抢领，最多两个请求在途；成功、抢完或明确失败即停止，最晚在开抢后 2 秒结束；显示领取结果，关闭设置窗口后继续运行 |

任务及特殊场景的已知验证情况见[功能说明](FEATURES.md#已知限制与验证边界)。
## 右键菜单

| 功能 | 用法 |
| --- | --- |
| 自定义菜单 | 添加、移除和拖动排序观鱼动作，也可恢复默认预设，保留官方菜单项 |
| 主播配置信息 | 悬停查看可取得的 CPU、显卡、设备、系统、直播分辨率及帧率 |
| 页面快捷开关 | 礼物栏、聊天活动区、PK、活动、广告及画面镜像；开关同步显示勾选状态 |
| 播放与功能入口 | 增益、团播预览、名单、状态刷新，多屏进入／退出／编辑及各类设置 |

多屏清晰度和定点换房位于主播标签的专用右键菜单。

## 通用

| 功能 | 用法 |
| --- | --- |
| 明暗主题 | 调整观鱼窗口与工具的主题；跟随斗鱼页面，也可固定浅色或深色 |
| 主题色 | 从斗鱼橙、青绿、湖蓝、藤紫、玫红五个预设中选择，应用于观鱼窗口与工具 |
| 统一设置草稿 | 跨分类修改后“保存全部”；关闭时可保存、放弃或继续编辑 |
| 即时预览 | 外观及可恢复的页面显示随修改预览，放弃后恢复；团播名单独立保存 |
| 设置搜索 | 页头输入分类、分区、名称或说明，即时显示可滚动的分组结果；组可折叠，改词后展开，点选设置跳转并高亮定位，无匹配直接提示 |

默认关闭的模式、显示项及需要手动执行的操作，见[默认关闭和手动操作](FEATURES.md#默认关闭和手动操作)。
